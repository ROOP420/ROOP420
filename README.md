## Production work

### Corporate Cruise

Corporate Cruise is a subscription-based office commute platform being built for Delhi NCR.

My work includes:

- Client, driver, admin, and backend applications
- Route operations and scheduling workflows
- Driver onboarding and verification integrations
- Background workers for CRM, email, PDF, and WhatsApp processes
- Live ride tracking with Redis-backed current state and persistent trip history
- Billing, wallet, referral, payout, and reconciliation workflows
- Production and staging deployment infrastructure

> The company source code is private. Public repositories on this profile will contain independent implementations, engineering case studies, and reusable backend systems without exposing customer data or company secrets.
